# 从重复行为学习未来新兴趣：到达概率预训练方案

日期：2026-09-28。状态：已撤回主推建议，保留讨论记录；未实现训练器，未构建正式训练数据，未提交作业。用户指出递推训练在监督信息来源上等同于扩充历史前缀 NI，后续讨论确认：递推未提供新的事实标签，现有依据不足以证明其相对直接 NI 监督的必要性或创新性。本文不得作为待执行方案或作业授权。不恢复此前被搁置的个人 CIR meta 方案。

## 1. 核心问题与判断

目标仍是预测相对冻结完整历史未出现、但在后续日志中被点击的兴趣类别。当前 Full Dev 不是动态首次兴趣形成评测；下述首次到达目标只用于训练侧辅助预训练，随后采用原 NI3 和原评价协议。

核心假设：重复兴趣行为能够提供用户向未来未见兴趣移动的状态信息。把这些行为直接当作 OI 输出标签，或人工删除兴趣再重建，并未直接训练“从当前状态到未来新兴趣”的预测量。可以让模型始终预测未来兴趣的到达概率，使重复行为通过状态之间的递推关系提供监督。

这是假设，不是已接受 CIR/OI 比较证明的机制。CIR 已有正向结果仍有效；其辅助目标与未来预测不同，不等同于存在测试集泄漏。

## 2. 预测量

对训练用户一个历史前缀 H_t，记录截至该位置的完整已见类别集合 S_t。模型输入文本最多保留最近 50 条，但新颖性判定不能只依据截断后的窗口。

对固定 108 类中的 c，若 c 不在 S_t 中，定义：

q(c | H_t, k) = P(c 在接下来 k 次观测点击中至少出现一次 | H_t)。

每个类别单独预测，多个类别可以同时具有较高概率，不要求 108 个分数之和为 1。一个类别到达一次即满足事件；以后重复出现不增加该类别的目标值。这里是日志点击事件的预测，不是潜在偏好、实际曝光后的接受概率或因果兴趣形成概率。

辅助任务的初始设计上限 K=10 个点击，k 取 1 到 K；这是待冻结的设计参数，不是数据推导的最优窗口。与直接目标对照逐条复用同一 (用户, t, k) 清单。只使用有完整 k 步后续记录的窗口，不把日志截断当作用户不喜欢或永不出现。不能将点击位置差称作实际时间差。

## 3. 一个递推目标

令 r_{t+1,c}=1 表示下一次点击的类别为 c，否则为 0。对当前未见的 c，有：

q(c | H_t, k)
 = E[r_{t+1,c} + (1-r_{t+1,c}) q(c | H_{t+1}, k-1) | H_t]，

并规定 q(c | H, 0)=0。

下一次就是 c，则当前这条路径的到达目标为 1；下一次不是 c，则剩余问题变成更新历史后、余下 k-1 步内是否到达 c。这里没有要求“下一次必须是新兴趣”：重复行为也能参与这种监督。

例如当前只见过 A、B，后续依次是 A、B、C、D、C：在五步观察窗口中，C 和 D 都是到达目标。前两步重复行为可以连接到后面的到达监督；C 的第二次出现不会被重复计数。例子仅说明目标定义。

训练时使用同一模型的 EMA 目标参数 theta_bar 计算：

y_{t,c,k} = r_{t+1,c} + (1-r_{t+1,c}) stopgrad q_theta_bar(c | H_{t+1}, k-1)。

L_arrival = 平均_{t,k} 平均_{c in U_t} BCE(q_theta(c | H_t,k), y_{t,c,k})，

其中 U_t = 固定输出词表减 S_t。终点 k=0 是精确的零步边界，不是对未观测未来填零。EMA 仅稳定辅助训练目标，不是额外训练的 LLM judge 或生成教师；不使用策略优化、奖励模型、在线交互或测试时参数更新。

递推等式在完整历史条件下成立。以 H50 表示历史时需要函数近似，不能声称该表示满足严格 Markov 性或保证收敛。单条后续路径也不是该用户的确定性转移规律。

## 4. 最小模型与训练流程

1. 使用原 Qwen3.5-2B、LoRA 和 108 个 SID 行。
2. 仅在辅助阶段的输入中说明 k；以原 SID logits 的 sigmoid 定义 q。辅助阶段采用上述 BCE，明确区别于现有原生全词表 token CE。
3. 继承 LoRA/SID，重置优化器和调度器，运行完全相同的原 NI3。
4. 最终使用原 prompt、原 108 类评分、原 Full Dev 指标及不做历史候选后过滤的协议。

最终部署不需要 horizon 输入、EMA 模型、未来轨迹或梯度更新。NI 微调后的分数不再声称是校准的到达概率。辅助阶段损失空间变化必须由同样使用 BCE 的直接监督对照控制，不能把它隐藏为 CIR 的普通变体。

## 5. 数据可行性与边界

本次仅对当前本地 processed Train 做了只读 CPU 计数：

- 21,600 行、21,600 个不同用户。
- 存储的历史长度中位数 14，75% 分位数 30，最大 50。
- 第五条行为之后共有 323,627 个位置，其中 166,614 个类别此前已在该存储历史出现，157,013 个为存储历史内首次出现，覆盖 125 个源类别。

输入：`data/processed/new_interest_static_user_disjoint_sft21600_h50_v1/train.parquet`。这些是可用位置的初步计数，不是合法辅助样本数；它们没有校正 H50 之前的原始历史，也未限定未来窗口或 108 个输出类别。

正式构造必须恢复这些训练用户的完整 raw seed history，用截断点之前的类别集合初始化 S_t，再在现有 H50 内取前缀/后续窗口。输出之外的 17 类保留为真实输入与状态更新，不从事件时钟中删除。不得使用 Dev 用户或 Dev 未来标签。若未来使用带时间戳的 impression 轨迹，同时间戳点击需按集合处理，不能人为规定顺序。

当前数据依然有有限观测窗口与曝光选择；只研究日志中的未来观测行为。不能由这个辅助任务得出用户兴趣被创造、长期采纳或无偏偏好结论。

## 6. 最小决定性实验

| 条件 | 辅助训练 | 后续 |
|---|---|---|
| A | 无 | 原 NI3 |
| B | 原 CIR | 原 NI3 |
| C | 直接未来集合监督 | 原 NI3 |
| D | 到达递推监督 | 原 NI3 |

C 对相同 (H_t,k) 直接构造 g_{t,c,k}=1[c 出现在接下来的 k 次点击中]，使用与 D 相同的 sigmoid/BCE、合法类别集合、数据和 horizon 条件化。这是不可省略的对照。

在完整观测、充分容量与理想优化下，C 与 D 对应相同的到达概率目标。因此 D 的可检验价值是有限样本下跨状态共享监督的学习效率或泛化，不是创造了 C 没有的事实标签，也不是拥有不同的 Bayes 最优目标。

首次原型先比较 C 与 D 在固定训练侧验证集上的结果，再决定是否进入正式 Full Dev。正式比较必须统一数值执行路径和 NI 训练；历史 A/B 仅能作为背景，不能忽略既有执行差异直接做严格贡献分解。

D 多一个目标状态前向，不能将相同更新数称作相同计算。分别报告辅助训练 token、前向次数、有效更新和 GPU 时间。若出现稳定优势，正式论文还需 C 的等计算预算对照、独立训练种子及第二数据集；具体数量和预算需另行冻结，本文不授权执行。

判据：

- D 优于 B 但不优于 C：收益可由直接未来监督解释，递推不成立为核心创新。
- C/D 只在训练侧前缀辅助任务改善，而原 NI 没有改善：不能认为辅助目标成功迁移。
- D 的优势被 C 的等计算版本消除：应定位为优化/计算分配现象，而非更有效的新兴趣方法。
- D 对独立评估稳定优于 B/C，尤其在预先划定的 NI 标签较少条件下更有效：才支持“重复行为提供可迁移的新兴趣监督”的学习效率主张。

本方案不安排换用户历史、同类别标题替换、个人 meta 或测试时适应实验。

## 7. 新颖性核查与诚实边界

本次读取了以下公开原文：

1. **BTBR**, *Masked and Swapped Sequence Modeling for Next Novel Basket Recommendation in Grocery Shopping*, RecSys 2023。https://arxiv.org/html/2308.01308v1 。已覆盖全部出现遮蔽、explore-only 末篮目标、遮蔽预训练后微调，并讨论遮蔽与时序之间的取舍。仅改整类遮蔽或首次出现前缀不足以主张首创。
2. **LLMs for User Interest Exploration in Large-scale Recommendation Systems**, RecSys 2024。https://arxiv.org/html/2405.16363v2 。已有兴趣 cluster、真实未来 novel transition、类别平衡 SFT 与分层推荐；“用 LLM 从旧兴趣预测新兴趣”不是独占贡献。
3. **A First-Occupancy Representation for Reinforcement Learning**, Moskovitz et al.。https://arxiv.org/html/2109.13863v3 。已提出区别于累计占据次数的首次占据表征及相关递推。首次到达、吸收边界和动态规划本身均不是本提案的数学首创。

可争取的贡献是：在用户相对的新兴趣预测中，把重复行为转成未来兴趣到达的辅助监督，并证明它比直接未来集合标签、历史恢复和额外计算更有效。这个贡献需要实验成立，且还要更全面检索推荐中的 temporal-difference prediction、successor features、first-passage/survival modeling 等邻近方法。

当前判断：问题与训练目标可明确对应，最小实现和反证对照可闭合；新颖性仍是候选，尚不能宣称已经满足“足够 novelty”。不以新方法名、现成递推公式或单次涨点代替这一判断。
