# 用户条件化有向兴趣迁移：第一版方法设计

本设计展开“哪个历史兴趣，在什么用户证据下，支持哪个新兴趣”的方法方向。建议采用**冻结的 Qwen3.5-2B SID 基线，加一个受限的有向迁移分支**，先验证单兴趣迁移，再检验双兴趣组合的增量。输入、108 类目标和真实 NI 标签保持现有定义。

核心假设是：类别名称之间的固定相似度不足以描述新兴趣迁移；同一个源类别，不同用户读过的具体新闻、阅读次数及位置会改变其对目标类别的预测作用。两个源兴趣还可能提供超出单个源兴趣贡献的组合信息。这里研究预测规律，不声称识别真实用户兴趣的因果来源。

**1．任务、信息边界与模型输出**

令 H₀ 为完整原始 History，H 为模型实际可见的最近 50 条历史。NI 标签 y 在 H₀ 中未出现，构造标签后再截取 H。每条训练样本继续保留一个兴趣 target，模型输出 108 个 SID 分数；所有类别都参与既定评估，不新增 history mask。

历史源类别与目标类别不相同：本次核实 Train 历史覆盖 125 个 leaf、20 个 parent；输出仍是既有 108 类。源类别不能因为不属于输出词表就被删除。未来点击文章、真实 target 名称及其它未来行为不进入特征分支；候选 c 的名称是所有 108 类都公开的固定标签定义。

“源兴趣”指用户历史中出现的兴趣，并不等于一个额外 OI 训练标签。真实 NI 样本本身已经提供 `多个旧兴趣组成的历史 → 新兴趣 y` 的监督。因此首版关系分支可以只用原 NI target 训练；既有 Mixed checkpoint 已作为底座使用了 OI。后续若加入 OI 效用路由或支持擦除，需要单列实验因素。

对每个候选 c，最终分数为：

\[
s_c(H)=z^0_c(H)+\gamma_1\delta_{1,c}(H)
+\gamma_2\delta_{2,c}(H).
\]

| 部分 | 读取的信息 | 作用 | 首版是否更新 |
|---|---|---|---|
| 基线 z⁰ | 原 B+I 完整 prompt，即模型可见 H50 | 保留现有预测能力，包括无法归属具体源兴趣的部分 | 冻结 |
| 单源 δ₁ | 每个源兴趣自己的标题向量、名称、次数和位置，与候选名称 | 学习用户条件化的有向迁移增量 | 第一次拟合更新 |
| 双源 δ₂ | 两个源兴趣自己的表示，与候选名称 | 学习超出固定单源模型的组合增量 | 第二次拟合更新 |

三部分对全部 108 类打分，因此可以提升基线 Top20 之外的类别；它不受先取 TopK 再重排的覆盖率上限限制。分数分解是相对于固定模型的操作性分解，不是每个兴趣真实作用的唯一分解。

**2．源兴趣表示：保留具体行为，隔离其它兴趣信息**

对每条历史新闻 j，读取现成的独立标题向量 v_j。按 leaf a 聚合，得到：

\[
\bar v_a=\frac{1}{n_a}\sum_{j:c_j=a}v_j,
\qquad
q_a=\operatorname{LN}(W_t\bar v_a+W_e e_a+W_m m_a).
\]

其中 e_a 是源类别名称向量；m_a 包含 `log(1+n_a)`、最后出现位置、平均出现位置、出现跨度等少量统计，位置按 H 中的序号归一化。原数据没有逐次历史点击时间时，只能称序列位置／最近程度，不能称相隔天数。重复行为继续计入均值和次数，不改成去重集合。

每个 q_a 只看该类别的行为；全历史长度可作为归一化尺度，首版不把完整类别频次向量、全历史文本或基线 hidden state 输入 q_a。否则单源项就能暗中读取其它源兴趣，无法检验后续组合项是否有必要。

候选表示为 `v_c=LN(W_e e_c)`，其中 e_c 按冻结 SID 映射的顺序，从 108 个候选名称向量读取。源与目标可共享名称投影 W_e，但后面的关系算子不对称。若 a 缺席，直接用存在 mask 排除该 slot，不能仅依赖某个带 bias 的网络把缺失输入映射到零。

现有独立向量可以直接复用：`all-MiniLM-L6-v2@1110a243fdf4706b3f48f1d95db1a4f5529b4d41`，384 维，编码器不更新。这样省去新一轮新闻 LLM 编码。所有 MLP、attention 和结构对照都读取相同缓存，防止把额外编码器／特征收益归因于迁移结构。

不能把完整因果 LLM 的历史 hidden states 按类别平均后，声称得到了独立源兴趣：这些状态已读过前序其它类别的信息。后续可以将这种特征作为性能消融，但必须放弃 source-only 的解释，并与隔离编码比较。

**3．单源迁移：少量共享、有方向的关系算子**

对源兴趣 a 和候选 c，建议用 R 个共享低秩算子：

\[
g_{a}=\operatorname{softmax}(G[q_a;m_a]),
\]
\[
T_a(c)=\sum_{r=1}^{R}g_{a,r}\,
\tanh\left(\frac{(P_rq_a)^\top(Q_rv_c)}{\sqrt{k}}\right).
\]

G 是一个很小的门控网络，只读本源的用户证据；它在关系算子之间分配权重，不直接读取完整历史。第一版也不让 gate 直接读取 c，候选依赖通过每个关系算子的目标投影进入。不同用户在同一类别内的标题及位置不同，q_a 和 g_a 因而不同；无需为每个用户保存 ID embedding。

方向性由独立的 P_r、Q_r 及源行为／目标名称的不同角色允许。它允许 a→c 与 c→a 不同，但不会强迫两者必须不同；不能仅因没有共享参数就声称学到了真实迁移方向。`P_r=Q_r` 只能称投影共享对照：两侧输入及 gate 仍不同，整体并不对称，参数量也有变化。真正的对称关系对照应在静态名称关系中使用同一表示、对称核与对称门控，再与容量匹配的有向名称关系比较。

把每个 T_a 在全部 108 类上减均值，记为 `T̃_a(c)`，聚合为：

\[
\delta_{1,c}=\frac{1}{|A(H)|}\sum_{a\in A(H)}\widetilde T_a(c).
\]

等权平均按不同源类别计数，防止长历史仅因 slot 更多就产生更大的分数。出现次数已经进入 m_a。正贡献表示相对于其它候选提高该类 logit；负贡献表示相对降低。它不是用户喜欢／厌恶的概率。

非线性放在每个源的贡献内部很关键。如果仅对双线性 `q_aᵀMv_c` 求和，整个模块可以折叠为“先聚合一个用户向量，再与候选做点积”，难以支撑比普通池化更具体的结构主张。即便采用上述形式，它仍可能被更一般的 attention/MLP 表达；贡献应是受限参数共享带来的泛化，而非新的万能表达能力。

**4．双源组合：在单源模型固定后拟合剩余误差**

先训练好单源部分并冻结全部参数，包括 W_t、W_e、W_m、G、P、Q 和 γ₁，再增加双源项。否则可以通过重新分配参数将单源效应转移到组合项，难以解释组合模块的增量。

建议采用一个共享、低秩、对两个源交换对称的交互：

\[
b_{ab}=\tfrac12[(Uq_a)\odot(Vq_b)+(Uq_b)\odot(Vq_a)],
\qquad
B_{ab}(c)=\frac{b_{ab}^{\top}(Wv_c)}{\sqrt{r_2}}.
\]

U、V、W 不带 bias。只计算不同源类别 `a<b`，并乘存在门控 `m_a^{present}m_b^{present}`。缺少任一源时，该组合项严格为零；只有一个源时，整个 δ₂ 为零。对 B 在候选维度减均值后，对存在的源兴趣对取平均：

\[
\delta_{2,c}=\begin{cases}
\binom{|A|}{2}^{-1}\sum_{a<b}\widetilde B_{ab}(c),&|A|\ge2,\\
0,&|A|<2.
\end{cases}
\]

例如，单独运动可提高运动营养的分数；运动和育儿一起出现时，组合项可能进一步提高亲子运动的分数。例子是机制示意，不是已验证的真实来源解释。组合项不被限定为正，也不强制同 parent。

低秩乘积避免每个 `(a,b,c)` 单独查表，从而允许参数迁移到训练未见的正向组合—目标配对。它本质上是低秩二阶集合统计，仍可先聚合再与候选点积，不是无法聚合的逐对推理：

\[
\sum_{a<b}b_{ab}=\tfrac12\left[
(\sum_aUq_a)\odot(\sum_aVq_a)
-\sum_a(Uq_a\odot Vq_a)\right].
\]

因此可以利用上述等价式优化计算，无需创建 125×125×108 的可训练自由参数表。与普通单源线性池化的区别在于二阶乘积特征；不能将“不可折叠”作为该双源模块的创新点。

`zero-at-missing` 保证结构上的存在条件，却不能解决相关兴趣之间的统计不可识别性；冻结主效应仅提供“在这个固定模型之上的增量”定义。不能直接称 functional-ANOVA 正交或因果分解。另外，基线本来就可能学会某些组合，δ₂ 没有收益只能说明它没有带来额外价值，不能证明用户没有组合兴趣。

**5．训练目标：单个 NI 标签直接监督最终分数**

首版保持单目标分类损失；每一步只约束当前新增的残差：

\[
L_{NI}=-s_y+\log\sum_{c=1}^{108}e^{s_c},
\]
\[
L^{(j)}=L_{NI}\big(z^{(j-1)}+\gamma_j\delta_j\big)
+\lambda_j\frac1{108}\sum_c(\gamma_j\delta_{j,c})^2,
\qquad j\in\{1,2\}.
\]

第一步的 z⁽⁰⁾ 是冻结基线，第二步的 z⁽¹⁾ 是冻结后的“基线＋单源”模型。残差幅度约束限制过大改动，不能保证保留全部基线性能；λ 用相应验证集选择。第二步不惩罚总残差平方，否则其中的交叉项会主动奖励双源项抵消已冻结的单源项。训练第一步只更新单源分支；第二步只更新双源分支及 γ₂。小幅、非退化初始化应保证乘积因子的梯度可达，不能把所有低秩因子同时初始化成零。

不需要为每条训练记录生成 bridge 标签，也不额外宣称一个“方向性 loss”。单正例只能监督最后排对 y，哪些内部关系成立需要靠结构限制与验证。尤其不让 LLM 为每个 target 编理由并将其当真值，不把现有 OOF 难度权重混入第一轮；这些会让结构贡献无法区分。

普通候选分布 CE 与现有底座的 full-vocabulary token-mean SFT 不是同一训练目标。新增分支和所有新增 head 对照统一采用上述 108 类 CE；原底座保持冻结。因此可以解释 head 间的差异，不能把“多训了一个 108-way head”的收益直接归给关系结构。

第一版可用的起始参数如下，它们是待冻结的工程初值，不是经过验证的最优配置：

| 参数 | 建议初值 | 理由 |
|---|---|---|
| 底座 | Qwen3.5-2B Mixed | 现有最好的同规模配方；用于普通 Dev 原型 |
| 文本编码器 | 现成冻结 MiniLM 缓存 | 独立编码且无需新增模型调用 |
| slot／候选维度 | 128 | 适配 21.6k 单目标样本规模 |
| 单源算子数 R | 4 | 少量共享关系，减少按边记忆 |
| 每个单源投影秩 k | 16 | 低秩、易做容量匹配 |
| 双源秩 r₂ | 32 | 小规模组合残差 |
| 训练器 | AdamW；head LR 初值 1e-3 | 大模型冻结，仅训练小 head |
| 验证目标 | 相应验证集的 Macro R@10，NDCG@10 辅助 | 区分 head-only 与全管线用户隔离，正式 Dev 不选超参 |

新增参数预期约十几万量级，实施时以实际参数清单为准。大模型只需缓存每条输入的全部 108 分数，关系 head 可在缓存上多轮训练；还需要记录缓存抽取和新增编码／head 的总成本，不能只报最后一个小 head 的耗时。

**6．训练／验证必须先切分，尤其注意底座泄漏**

已有 Mixed adapter 使用完整 21.6k NI 标签训练。它适合做既定 Dev 上的工程增量实验，但不能拿它来证明某个训练边／组合“从未见过”。即使只让新 head 不看保留边，底座也已经见过这些标签。同样，完整 Mixed 上划出的 Train 内验证用户只对新增 head 是未见用户，属于 head-only validation；这种早停／超参结果必须在底座也排除验证用户的确认实验中复核。

建议区分两个目的：

| 目的 | 合法起点 | 可以声称什么 |
|---|---|---|
| 现有模型工程增量 | 已验收完整 Mixed，冻结后新增 head | 相对于该底座，在既定外部 Dev 的增量；开发集已多次看过的限制仍需报告 |
| 机制与组合泛化确认 | 先划用户／边，再从通用 pretrained 与不含行为配对的 SID 初始化训练底座 | 对全部监督组件未见的正向关系／组合配对的泛化 |

确认实验中，可先采用一个固定的 fit／validation／probe 用户划分，具体比例在支持度审计后冻结；需要基线训练时就排除 validation 和 probe 用户。全部 OI、NI、任何派生视图都继承用户归属。当前最小版本不做 meta-utility，因此不用增加昂贵的五折 OOF；若未来加入 utility，另划 meta-utility 用户，不能再称其为独立验证。

两个额外 probe 的区别也要明确：

- **边保留**：保留 a→c，排除全部监督训练中 `a∈H 且 target=c` 的记录；c 仍在其它来源的训练记录中出现，a 也在其它目标记录中出现。对于多源历史，只要含 a 就按规则处理，不能因另一个 anchor 解释了该条记录而让它漏回训练。
- **组合保留**：保留 `(a,b)→c`，排除全部同时含 a、b 且 target=c 的监督记录；同时确保 `a→c` 与 `b→c` 的单源／其它上下文记录在 fit 中有足够支持。它测试的是未见组合—目标映射，而非未见类别。

上述 holdout 保证的是未见正向配对。全 108 类 CE 中，含 a、但 target≠c 的样本仍让 c 参与竞争并收到梯度；不能声称 a→c 完全没有任何监督接触。组合同理，应报告保留映射在其它 target 样本中的竞争曝光量。除非另设并统一实施候选梯度屏蔽协议，否则不能升级为完全未接触关系的实验。

保留清单、用户分组、训练余量及每个目标支持数须在拟合前固定；根据支持度合并或放弃无法评估的组，不能根据方法优劣挑边。统计支持不足时只报告探索性结果。固定 MiniLM 对所有文本逐条编码不使用标签，可以跨分割复用；任何学习到的投影、归一化统计、关系矩阵及底座 adapter 都必须遵守 fit 边界。

**7．最小实验矩阵与解释条件**

| 条件 | 新增输入与模型 | 回答的问题 |
|---|---|---|
| A：冻结基线 | z⁰ | 起点 |
| B：分数校准 | z⁰＋温度／类别偏置 | 收益是否只是类别先验或数值尺度校正？ |
| C：普通残差 head | 同一套标题／名称／统计输入，参数匹配的 MLP 或 target attention | 收益是否仅来自额外特征、容量和训练？ |
| D：静态关系 | 关系只由源类／目标类名称决定，不读本用户标题与源统计 | 用户条件化是否有价值？ |
| E：单源迁移 | z⁰＋δ₁ | 受限的有向关系是否有效？ |
| F：单源＋双源 | z⁰＋固定 δ₁＋δ₂ | 组合增量是否有效？ |

E/F 还需检查静态对称名称关系、投影共享、可折叠双线性、相同参数量单源 head 等针对性消融；不必在最初管线验证时铺开全部。为区分两次拟合与额外训练量，给 E 相同总 label 曝光／继续训练预算，并给 C 同等 head 预算。还必须加入“冻结同一个 E，再增加参数量及训练预算匹配的第二个单源残差 head”，与 F 逐阶段匹配，区分双源乘积与单纯增加参数／再拟合一次残差。F 的额外成本需单列。

另外要评估迁移分支单独使用的版本。如果不加 Qwen 基线就能达到相同成绩，说明轻量结构本身已足够，不能宣称收益来自大模型与迁移的互补。第一轮不以最终总表的小幅增长为唯一依据。

主结果保持正式 interest-macro Recall/NDCG@10、@20；附边／组合 probe、同 parent／跨 parent、历史长度、低支持关系的指标。用户为重采样单位，训练 seed 波动与用户 bootstrap 区间分开报告。用于校准或早停的数据不再充当最终 probe。

模型内贡献可列出“目标 c 的单源／双源增量”，再做相同源类别内的跨用户标题替换、slot 删除敏感性等诊断。删除 slot 时应明确是否只改新增分支，还是也重新计算基线输入；前者测新增结构，后者混合底座与分支效应。二者均不证明改变真实用户历史会引起同样的行为变化。

放弃或降级主张的条件包括：静态关系与用户条件关系等效；普通同容量 head 复现全部收益；组合保留上无增量；源标题在同类用户间打乱仍无损；或者新分支只修正类别偏置。未见这些排除性证据前，命名为结构化预测增量比命名为已识别的“兴趣迁移机制”更准确。

**9．论文贡献应怎样表述**

当前可以提出的研究假设是：**通过隔离历史源兴趣表示、共享有方向的低秩关系算子，并显式建模双源交互，能够提高对未见正向兴趣迁移配对的泛化。** 方法上不必同时加入 teacher、CoT、GRPO、证据擦除和梯度路由；这些都只能在结构验证后作为独立问题展开。

[GemiRec](https://arxiv.org/html/2510.14626v1) 已有未来兴趣 posterior 和 Category-Unseen Recall，[Google 2024](https://arxiv.org/html/2405.16363v2) 已有历史 cluster 组合到 novel cluster 的训练，[CauseRec](https://arxiv.org/html/2109.05261) 已有兴趣层面的证据扰动。低秩双线性／三阶交互也属于已有建模工具。因此新颖性不能由这些零件的名字提供，需要由受限信息流、具体结构、对未见关系的验证及超越强对照的证据共同支撑。

本设计是下一步可实现的研究方案。单源有效后再检验组合；组合确认后才考虑联合微调底座。后者可能提高性能，但冻结分解的解释边界会改变，必须作为新版本重新验证。
