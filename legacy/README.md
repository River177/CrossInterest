# Legacy Material

This directory isolates material that is not part of the active CrossInterest
MIND pipeline. Nothing under `legacy/` is an input to current builders,
training, or evaluation.

- `toys_and_games/docs/` contains the tracked historical category analysis.
- `toys_and_games/raw_meta_Toys_and_Games/` is local raw data and remains
  ignored by Git.

Do not add dependencies from active code to this directory.
